Single-schema Prisma project rooted at `schema.prisma` targeting a PostgreSQL datasource with the generated client emitted to `../generated/prisma`. The schema declares six core entities — `User`, `Category`, `Product`, `Variant`, `Cart`/`CartItem`, `Order`/`OrderItem` — plus supporting tables `PaymentEvent` and `OrderCounter`. Domain state is modeled via enums (`Role`, `ProductType`, `ProductStatus`, `OrderStatus`, `PaymentMethod`) rather than lookup tables. Relationships use explicit `@relation` declarations with cascade/restrict policies: product images and cart items cascade on delete, categories restrict deletion, and user→order uses `SetNull`. A composite unique constraint on `(cartId, variantId)` prevents duplicate cart entries. Versioned migrations live under `migrations/` (timestamp-prefixed folders) managed by Prisma's migration engine (`migration_lock.toml`). `seed.ts` bootstraps initial data using `PrismaNeon` adapter, bcrypt-hashed admin user, and upsert-driven category/product/variant population.
